# spectrum-analysis

A simple spectrogram/audio visualizer built in Python as a foray into signal processing. No numerical values are displayed, though a rewrite with ImGui is planned to address this. More views and analysis tools may be added in the near future.
## Run Locally

1. Clone the project

```bash
git clone https://github.com/PixelTomato/spectrum-analysis.git
```

2. Select project directory

```bash
cd spectrum-analysis
```

3. Install dependencies (consider a .venv)
```bash
pip install pyaudio numpy soundcard
```

4. Run

```bash
python main.py
```
